# Structure-to-route map

Use this file after the original matrix has been read and its dimensions have been checked. A signal proposes a hypothesis; it never proves the semantic class by itself.

## First split: what is actually blocking progress?

| Observed state | Primary objective | First research question |
|---|---|---|
| No strict feasible point | feasibility / primal | Is infeasibility local and combinatorial, or is the current candidate merely numerically invalid? |
| Good incumbent, weak root or best bound | dual / formulation | Which extended variables make the LP weak, and can the objective be projected onto a smaller core? |
| Strong bound, poor incumbent | primal | Which variables/components carry the remaining disagreement, and what neighborhood scale can cross it? |
| Narrow integer cutoff | proof | Can the residual decision problem be encoded exactly in SAT/PB/DP and emit a replayable certificate? |
| Tiny numerical gap | audit first | Is the alleged improvement larger than objective and feasibility tolerances, and are all integer values exact enough? |
| Solver repeatedly follows the same trajectory | representation | What structural reformulation, decomposition, or invariant changes the search space rather than only parameters? |

## Structural routes

| Matrix or solution signal | Verify before acting | Why the route fits | Candidate methods | Early rejection / pivot condition |
|---|---|---|---|---|
| Objective depends on `n` selection variables but the formulation has `O(n^2)` ordering binaries and big-M disjunctions | Recover release, duration, latest start/deadline semantics; test each proposed inequality on tiny exhaustive cases | Pairwise order variables create fractional overlap and obscure the real selected-set decision | Project to selections; deterministic conflict graph; interval energetic cuts; common-deadline release-suffix master; CP-SAT `NoOverlap` for construction | Any cut removes an exhaustively verified feasible schedule; deadline semantics are ambiguous; master is used as if equivalent without a lifting proof |
| Optional jobs share one machine/resource and deadlines or release times cluster | Confirm a common safe horizon and mandatory energy in each interval | Aggregate resource demand can dominate millions of pairwise disjunctions | Energetic reasoning, edge finding, interval clique cuts, suffix/prefix capacities, time-indexed or CP interval model | Endpoints are not safe, multiple resources destroy the one-resource projection, or the master bound remains far below the incumbent |
| Endpoint choices induce intervals; compatibility is transitive/acyclic | Prove every original OR/transition row depends only on endpoint intervals | Scheduling becomes a chain cover problem | Interval-order DAG, bipartite maximum matching, minimum path cover, clique/antichain bounds, colored matching for construction | A purported compatibility arc violates an original row, or interior variables affect feasibility beyond endpoints |
| Objective/load values lie on a lattice (parity, gcd, modular residue) | Derive the lattice from exact integer coefficients and bounds | A coarse continuous bound can be rounded to the next attainable value | Parity, gcd rounding, modular cuts, residue DP | Continuous coefficients or scaling invalidate integrality; residue class is not preserved under all feasible moves |
| Many columns are repeated up to group labels or a large permutation action | Verify identical coefficients/costs under the claimed action; prove group coverage | Search is spending time on interchangeable labels | Orbit/type quotient, multiplicity variables, orbitopes/symmetry breaking, canonical representatives; prove projection and lift (e.g. flow/Gale-Ryser) | Costs or side rows break the action; not every quotient point lifts; only duplicate names, not duplicate algebra, were observed |
| Assignment/permutation/QAP core with side constraints | Confirm one-of-k rows and item/resource incidence exactly | Matching/flow gives a strong polynomial core and exposes the small hard side system | Bipartite matching, min-cost flow, bottleneck matching, Hall deficiency, QAP reduction, cut-chain enumeration | Side constraints dominate the core so the relaxation is weak; mapping back is incomplete |
| Unit-coefficient covering rows and binary columns | Normalize row orientation and RHS; audit dominated rows/columns and forced choices | Set-system structure supports exact reductions and combinatorial dual bounds | Dominance, forced columns, greedy/dual ascent, Lagrangian pricing, rational LP dual, disjoint-row packing, conflict graph, PB/MaxSAT cutoff | A bound exceeds the LP relaxation without a valid strengthening; parser reverses row sense; SAT returns `UNKNOWN` or no proof trace |
| Unit-coefficient packing/conflict rows | Confirm pairwise conflicts are valid in the original model, not artifacts of a candidate | Feasibility and local improvement can be reasoned on a conflict graph | Cliques, odd cycles, independent set, set packing, ejection chains, PB/SAT | Conflict graph omits higher-order constraints; graph optimum cannot be lifted to the MPS |
| Precedence/closure variables plus few resource/budget rows | Verify closure arcs and sign conventions | The closure core is min-cut solvable; only few resources cause hardness | Maximum closure/min-cut, Lagrangian relaxation of resource rows, bundle/subgradient, resource-state DP | Remaining rows are not few/global; relaxed solutions cannot be repaired or give weak duals |
| Many local blocks coupled through a small set of master rows | Confirm blocks have private variables and become independent when master rows are removed | Decomposition can replace a huge monolith by stronger block convex hulls | Dantzig-Wolfe/column generation, Benders, Lagrangian decomposition, block-specific cuts | DEC blocks contain no private variables; removing master rows does not separate; pricing is as hard as the original without reuse |
| Finite-section structural/truss design with equilibrium `Bq=f`, compatibility `B^T d`, material law, and on/off `q=x*sigma` | Identify member-local templates; separately label equilibrium, compatibility, constitutive, and capacity rows; test components after removing only verified coupling families | Each member has a small disjunctive hull, while sparse physics rows couple members globally | Equilibrium-capacity relaxation, member convex hull/perspective cuts, Lagrangian equilibrium, Farkas/Benders feasibility cuts, dual-sensitivity multi-member LNS | A removed row was needed for the claimed bound direction; local hull gives no root gain; pricing retains the full global physics problem |
| LP fractionality concentrated in a few blocks/times/components | Measure fractionality and incumbent-vs-relaxation support differences | A focused exact neighborhood can cross the active barrier cheaply | RINS/local branching, block/time-window LNS, multi-block release, repair MILP/CP | All tested small neighborhoods close with no improvement and historical differences span many blocks; pivot to coupling/convex-hull work |
| Candidate differences form one large conflict-connected component | Compute components using original affected rows, not just variable indices | Independent or single-flip moves cannot realize the observed transition | Multi-remove/multi-add exchange, ejection chains, label setting, meet-in-the-middle, component-wide LNS | Candidate itself fails strict integrality; component analysis depends on tolerance-only support |
| Geometry/non-overlap with rectangle coordinates or pairwise separation binaries | Recover exact dimensions, rotations, bounding box, and separator semantics | Coordinates are often a weak continuous representation of a finite relative-order problem | Sequence-pair, no-overlap CP, area/projection bounds, guillotine/separator DP, Benders on relative order | Sequence representation is not complete for allowed geometry; obstacles/rotations are omitted; area bound is used as sufficiency |
| Graph invariant, finite coloring/cutwidth/genus/Steiner state | Prove the MPS-to-graph crosswalk and objective sign | A compact discrete object often admits exact DP, enumeration, or SAT | Tree/subset DP, cyclic enumeration, rotation systems, Steiner state DP, SAT/PB with proof logging | Vertex/edge labels or multiplicities do not match; an external theorem concerns a different graph |
| Algebraic tensor/orbit structure and repeated cyclic layers | Recover exact equations and group action; inspect slice ranks and tight rows | Algebraic invariants can exclude entire objective levels that local MIP search cannot | Rank/slice bounds, orbit classification, canonical support, finite case enumeration, algebraic symmetry moves | A support-only relaxation ignores tensor equations; local support closure is extrapolated to a global bound |
| A solved sibling or alternative formulation has a strong solution | Build a positional/semantic crosswalk and audit changed rows | Transfer can cheaply provide a high-quality starting point and reveal the small differing subsystem | Sibling transplant, fix shared design then reoptimize recourse, warm start, paired-formulation cross-check | Names align but algebra does not; recourse repair is infeasible; transferred objective is not evaluated in the target MPS |
| A tiny target gap can be phrased as “no solution at cutoff K” | Establish an exact integer/rational cutoff and encoding equivalence | A decision proof may be easier and more portable than a complete optimization trace | CNF+DRAT/LRAT, OPB+VeriPB, exact DP/exhaustive enumeration | Floating cutoff is ambiguous; encoding is one-way only; solver says UNSAT but independent checker does not pass |

## Ranking routes

Score each proposed route from 0–3 on:

1. **Exactness of the structural mapping** — guessed, partially checked, or both-way proved.
2. **Decision-space compression** — cosmetic, moderate, or orders-of-magnitude.
3. **Decisive artifact** — heuristic log, strict witness/bound, or portable proof.
4. **Cost of the falsification test** — expensive, moderate, or cheap.
5. **Family leverage** — one-off, sibling reuse, or reusable theorem/solver.
6. **Known blocker penalty** — missing parser/proof backend/data, weak relaxation, or none.

Prefer a route that can become false quickly and, if true, produces a checkable artifact. Do not rank solely by the displayed MIP gap.
